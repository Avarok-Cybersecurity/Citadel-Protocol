pub const FILE_GROUP_HEADER_UNANSWERED_FAILS_WITHIN: Duration;
Expand description

The worst case for reporting an unanswered group header, counted from when the header was first in line: FILE_GROUP_HEADER_ACK_DEADLINE (15 s) plus one FILE_GROUP_CHECK_PERIOD (1 s), because the deadline can pass just after a check: 16 s. This is the figure the workspace UI’s idle timeout for a file send (30 s, the parent repository’s TIMEOUT.FILE_SEND_MS) must exceed, so the coded failure is what a person sees; it leaves 14 s between them. The SDK cannot read the UI’s constant; the parent asserts the ordering.
