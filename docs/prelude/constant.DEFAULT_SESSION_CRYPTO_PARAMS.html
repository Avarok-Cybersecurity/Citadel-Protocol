pub const DEFAULT_SESSION_CRYPTO_PARAMS: CryptoParameters;
Expand description

The cryptography of a session whose application names none: ML-KEM-1024 (FIPS 203, category 5) with AES-256-GCM and no per-packet signature. This is the only place a session’s KEM is chosen for it; everywhere else the KEM is named by the caller.

Both ends of a session agree on its suite from what the initiator sends. To run ML-KEM-768 instead, name KemAlgorithm::MlKem768Fips203 with SessionSecuritySettingsBuilder::with_crypto_params.
