Module floor 

Expand description

C1, C4, C5: the message floor of a negotiated key epoch. The message floor of a negotiated key epoch (§5.3 C1, C4, C5).

Once the peer retires an epoch it has said it will send nothing more under that epoch’s version, so a later message frame under an older version is not a straggler but a violation (C4). The same holds for a message frame below the agreed level (C5): a peer that agreed Extreme cannot quietly keep sending Standard. Ratchet control frames are exempt; they carry their own version logic. A refused frame keeps its place in both orderings of the channel, so the frames after it are not held back, and the application never sees it.
