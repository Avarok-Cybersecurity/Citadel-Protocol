Module key_epoch 

Expand description

The KeyExchange port: a negotiated key profile as one steered ratchet round. The KeyExchange port over a P2P connection’s ratchet manager (§2.1, §5).

The negotiator (N0) decides; this adapter carries the key profile out. Only the Leader issues Command::ApplyKeyEpoch (D2), which becomes one steered round ([KeyExchange::apply]). On the other side the round reaches the ratchet manager, which asks the gate installed here; the gate asks the negotiator (admit_key_round) and holds a round the negotiator answers with Wait until a later step lets it agree, bounded by the apply deadline. A round it builds is reported to the shell as an [AdmittedRound], whose outcome ([KeyEpochPort::round_outcome]) the shell feeds back as Input::KeyOutcome.
