Module lane 

Expand description

The in-channel negotiation lane: control frames that ride a P2P connection’s reliable, ordered message stream beside the application’s messages, never delivered to it.

A lane frame is a UserMessage whose ticket is LANE_TICKET. The peer’s SDK takes every such frame off the stream before the application sees it (see driver). The first frame each side sends is its [Hello]: the one the application gave PeerChannel::open_negotiation, or an empty one (nothing negotiated in band) once it splits the channel without opening the lane.
