The RobustConnectionManager’s protocol side: the node’s link mode and its clock. The RobustConnectionManager’s protocol side The protocol’s side of the RobustConnectionManager (ROBUST-CONNECTION-MANAGER.md §2.1): the node-wide mode that selects it, the clock it reads, the C2S pieces of lane L1 (cancelling an in-flight connect, §9.1), and lane L2’s P2P manager. Each kind of link reaches the kernel in one order, path → seal → deliver, through the citadel_link::LinkEstablisher contract, and a [manager] keeps it existing while the user keeps it open. The decisions live in citadel_link; this module is its I/O.
