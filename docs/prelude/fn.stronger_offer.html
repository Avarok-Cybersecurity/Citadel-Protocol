Expand description

The settings a link takes when two offers for it cross.

Every strength-ordered setting takes the stronger of the two offers’ values: the security level (by SecurityLevel::value) and the secrecy mode (Perfect over BestEffort). The crypto parameters and header obfuscation are a suite, not a scale, so they are never mixed: they come whole from the leading offer – the one with the higher (level, secrecy, KEM strength) – and a tie is broken by a fixed total order on the suite. The result is therefore the same whichever argument is which.
