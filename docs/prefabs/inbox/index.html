Module inbox 

Source
Expand description

Event inboxes a prefab fills for an application that may never read them.

A prefab cannot know whether its application will take an event receiver. Events go to an InboxSender; the application takes the receiver from an InboxClaim. Until it does, events wait in a backlog of at most UNCLAIMED_BACKLOG, and are flushed to the receiver when it is taken. An event that finds the backlog full, the receiver dropped, or every claim handle dropped is disposed of at once by Unclaimed::dispose: a file offer is declined, so its sender learns the answer, and a channel is closed.

Constants§

UNCLAIMED_BACKLOG
How many events wait for a receiver nobody has taken yet. Enough for the events that arrive between a connection’s start and the application taking its receiver; beyond that, an application that has not taken it is not reading it.
