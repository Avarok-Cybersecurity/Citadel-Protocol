Module bound_frame 

Expand description

C7: negotiation frames bound to their connection. C7: a negotiation frame is bound to the one P2P connection it belongs to (§5.3).

Key identity used to be (cid, version), and two connections of the same pair both start at version 0, so a stale connection’s packet was tried under the new connection’s keys. A sealed frame carries, in the clear and inside its AEAD’s associated data, a tag, the connection’s id, the ratchet version it was sealed under and the level. A frame from another connection is refused by its header before any key is tried, and no edit of the header survives the AEAD. The lane that carries these bytes is the in-channel SignalPort (lane SDK3).
